ND Central Remake - Development Plan

1. Final Choice of Databases and Software Platforms

We will be using MySQL from class as our relational database. Our programming languages will be Python, HTML, CSS, and JavaScript. Python will be used for the backend application and communication with the database, while HTML, CSS, and JavaScript will be used to build the user interface.

Our application will be developed and hosted using the resources provided on db8.cse.nd.edu.

2. Relational Schema

Our relational schema will contain tables for users, dorms, events, organizations, locations, interests, reviews, and event attendance. We will also use relational tables to connect users with their interests and events with the dorms and interests they are associated with.

We will design the relationships between these tables before beginning the main application development. This will allow the database structure to support the searching, filtering, personalization, and event management functionality of our application.

3. How Will We Get Data?

We have emailed ND Central to ask how we could access the database behind their website. We plan to use information from ND Central to populate our database with realistic Notre Dame event information.

We will also have user-generated data in our system. Students, organizations, and dorms will be able to contribute events, while users will be able to save events, indicate attendance, select interests, and eventually provide reviews.

4. What Will Everyone Do?

Clint: Will work on the frontend pages and HTML.

The remaining responsibilities will be divided among the other members of the group as development progresses. Members will work on the database, backend programming, frontend development, data preparation, and advanced application functionality.

5. Timeline

We plan to meet once a week, and sometimes twice a week, to discuss updates on the project, divide tasks, and coordinate development.

Before Fall Break

  • Finalize the relational database schema.
  • Finalize the relationships between all major tables.
  • Determine the primary keys and foreign keys for each table.
  • Write and test the MySQL code needed to create the database tables.
  • Make sure the tables and relationships work correctly on db8.

Our goal is to have the relational schema and the code required to create the actual database tables completed by Fall Break.

After Fall Break

  • Populate the database with initial event, organization, location, and dorm data.
  • Continue developing the Flask/Python backend.
  • Implement the basic event searching and database functionality.
  • Continue developing the HTML, CSS, and JavaScript frontend.
  • Connect the frontend to the database through the backend.

Later Development

  • Implement user accounts and dorm-specific functionality.
  • Implement organization and dorm event posting.
  • Implement event saving, attendance, and reviews.
  • Develop the personalized event recommendation system.
  • Develop the smart event schedule and conflict detection system.
  • Test the application and fix database, backend, and frontend issues.
  • Prepare the final demonstration and project report.
